# Security Policy

## Supported versions

The latest Delvefold 1.x release receives security and data-safety fixes. Pre-1.0 builds are unsupported after the 1.0 release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose server data, bypass authorization, escape configured filesystem boundaries, or cause destructive world operations. Use GitHub's private vulnerability reporting for this repository when available. Include the affected version, impact, reproduction steps, and the smallest safe proof of concept.

Do not include real credentials, private server addresses, player personal data, or an irreplaceable world. Keep a complete offline backup before reproducing any filesystem or world-lifecycle problem.

Ordinary crashes, configuration errors, and compatibility problems should use the public bug-report template.
